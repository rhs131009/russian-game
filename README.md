# Русский · Тренажёры

Восемь тем в одном статическом сайте: корни, падежи, склонения, ударения, двойные союзы, сложные предложения, суффиксы (задание 11), наречия О / А.

Суффиксы: 225 карточек с объяснениями, фильтры по частям речи, 10 экзаменационных вариантов с выбором нескольких рядов и разбором каждой пары.

Наречия: 32 задания с выбором пропущенной буквы и объяснением способа образования после ответа. Есть теория, ограничения правила и контрастные пары. На странице доступен выбор части речи: существительные, прилагательные, глаголы, наречия.

Прогресс и ошибки каждой темы хранятся отдельно в браузере. Новые темы используют ключи suffixes-v1 и adverbs-v1; данные остальных игр не изменяются. Сайт работает без сборки.
